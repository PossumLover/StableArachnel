# Sprout v0.3.7

- Games that also have Linux or Mac versions on Steam, such as Valheim and Core Keeper, no longer install a mix of every platform's files. That mix made them close at startup or sit on the loading screen. Sprout now gets its Steam plugin from Sprout's own fixed build. Updating Sprout no longer swaps that plugin back for the official one, which still has the problem. If a game already has the mixed files, verify its files once to repair it.
- Plugins built against Sprout compile again. The plugin kit now links QtConcurrent, which the plugin catalog code needs.
- Games launched with the Steam overlay switched on no longer quit immediately when they have launch arguments that start with a dash, such as Valheim's Vulkan option. The Steam Linux Runtime had read those arguments as its own options.
- The Steam overlay switch in game settings now shows whether the overlay will actually load, and switching it off turns it off. Before, it only controlled the Steam Linux Runtime route, so games like Valheim kept shift+tab with the switch off.
- Launch options can use a wrapper command by name, such as `mangohud %command%` or `env -u NAME %command%`. Before, Sprout needed the full path and showed "File not found".
