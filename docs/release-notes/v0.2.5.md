# Sprout v0.2.5

A crash fix, clearer catalog errors, and a list of Hydra sources you can add in one click.

## Fixes

- **No more crash while Sprout reads magnet links in the background.** To tell installers from portable games, Sprout peeks at the file list of the magnet links in your catalogs. It started a whole torrent session for every link and waited on it in a way that could crash on Windows (crash reports point at libtorrent). It now keeps one session for the whole list and never waits on it, and it reads the file list without downloading any of the game.
- **Catalogs say why they don't load.** Some catalog sites now only let web browsers in (a Cloudflare check), and some catalog files were taken down. Instead of a bare 403 error, Sprout says which it is, both when you add a catalog and in the catalog list. Catalogs on hydralinks.cloud only work in Hydra itself, so Sprout can't load them.
- **Online Fix "Self-protection failed" on Windows.** Sprout now spots this error box on Windows too, not just on Linux. If you put a SteamFix kit in `%APPDATA%\Arachnel\Arachnel\kits\steamfix`, Sprout closes the game, switches it to SteamFix and starts it again.
- Russian is complete again. The Sprout rename had left about 130 lines in English.

## New

- **Browse Hydra Library**, in Settings → Hydra catalogs, lists the sources from Hydra Library (library.hydra.wiki) with their game counts and labels such as Trusted or Use At Your Own Risk. Search the list and press Add. Sprout checks each source as you add it, so one that won't load tells you why instead of being added. Sources hosted on GitHub and similar sites work fine.

## Updating

- **Windows:** use Update now in the app. The installer runs by itself and reopens Sprout.
- **Linux AppImage:** from 0.2.1, Update now swaps the AppImage in place and restarts Sprout. On 0.2.0, download this AppImage by hand once.
