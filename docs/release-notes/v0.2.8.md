# Sprout v0.2.8

Fix Windows window resizing, including the border issue described in [upstream issue #55](https://github.com/BadKiko/Arachnel/issues/55).

- Resize the launcher from any edge or corner while keeping the custom title bar.
- Show horizontal, vertical, and diagonal resize cursors.
- Disable the custom resize handlers while maximized or fullscreen.
- Apply the same fix to the crash report window.

The launcher keeps its existing minimum size of 1100 x 720. Linux keeps its native window frame. The Snap Layouts hover menu requested in the upstream issue is separate from this resize fix.

Windows builds run native tests for all eight resize directions, window styles, minimum size, and maximize/restore. Both platforms run QML interaction and existing download/activity regression checks before publication.

## Downloads

- **Windows:** `SproutLauncher-0.2.8-Setup.exe`
- **Linux:** `SproutLauncher-0.2.8-x86_64.AppImage`
