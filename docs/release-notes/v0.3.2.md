# Sprout v0.3.2

Poppies and a butterfly now frame the library banner, a glasshouse appears in empty states, and terraced hills run along the bottom of each page. The light theme shows the garden in daylight, and the dark theme brings out a crescent moon.

The library and catalog cards give the flowers their own space. On narrow cards, the illustration steps aside so the text and buttons have room.

## Downloads

- **Windows** — `SproutLauncher-0.3.2-Setup.exe`
- **Linux** — `SproutLauncher-0.3.2-x86_64.AppImage`

SHA-256 hashes for both downloads are in `checksums.sha256`.
