# Sprout v0.2.3

A Windows cleanup: launches no longer carry Wine and Proton settings that only mean something on Linux.

## Fixes

- **Windows launch logs no longer list Wine settings.** For games with Online Fix, Sprout worked out the Wine DLL overrides (`WINEDLLOVERRIDES`, the long `d3d11=n;...;winmm=n,b` list) and a Proton prefix path on every OS, and printed both in the launch log on Windows too. They never reached the game: Windows starts games with Sprout's own environment, and only Wine reads that variable anyway. The log now shows only what the launch actually uses.
- **No more empty Proton folders on Windows.** Every launch made an empty `compatdata` folder for the game in Sprout's data folder. The ones already in `%APPDATA%\Arachnel\Arachnel\compatdata` are empty and safe to delete.
- **Unsteam games on Windows** skip a Proton-only helper that couldn't run there and logged "Steam detection will fail" for nothing.
- When a game's exe can't be found on Windows, the log says so instead of blaming a missing Proton.

Linux is unchanged: Proton launches get the same overrides and prefix as before.

## Updating

- **Windows:** use Update now in the app. The installer runs by itself and reopens Sprout.
- **Linux AppImage:** from 0.2.1, Update now swaps the AppImage in place and restarts Sprout. On 0.2.0, download this AppImage by hand once.
