# Sprout v0.2.15

- Add an **Open game folder** button to the game details page and game settings. Installed games open directly in your system's file manager, including games installed outside the default library folder.
- Show a clear notice if a game's folder is missing or the file manager cannot open it.

Includes everything in v0.2.14, including achievement name matching and support for game-local Goldberg/GSE achievement saves.
