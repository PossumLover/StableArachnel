# Sprout v0.3.3

- Library has one heading and one game count. Rounded search and filter controls sit above the grid. Long titles wrap, and the featured game shows the last session duration when available.
- Automatic plugin updates appear in Downloads. You can browse your library and play games from other sources while a plugin updates.
- In Friends, choose **Compare libraries**. Export your installed games and share the file with a friend, or open their file to see shared games and suggest one. Sprout matches Steam app IDs and compares Steam build numbers when both copies supply them.
- Achievements show when progress is unknown and let you inspect the save locations Sprout checked.
- Catalog has labeled search, sort, and filter controls. Missing artwork displays the game title on a themed cover.
- On Linux, Sprout updates the old Arachnel menu shortcut and keeps its existing launch command.
