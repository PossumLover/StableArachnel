# Sprout v0.2.12

- Fix a crash right after a Steam (steamidra) game finished installing, and when resolving its launch executable. The game activity fields added in v0.2.7 and v0.2.10 (play time, last session, play status) sat in the middle of the library record that Sprout hands to source plugins, so plugins built against the earlier layout read the wrong fields and wrote into Qt's read-only memory. Those fields now sit after the part plugins read, and the build fails if that part changes again.

Includes everything in v0.2.11: catalog grouping for additional release formats, the updater shutdown fix, TorBox cache badges, library lists and sorting, achievement filters and notifications, and the adult-game switch in Catalog filters.
