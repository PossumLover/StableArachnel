# Sprout v0.3.1

This release focuses on keeping game files, library records, and downloads intact when a drive disconnects or an operation fails.

- **Libraries and storage:** Moving a game between drives preserves hidden files and symlinks and verifies the copy before deleting the original. Existing destinations are left alone. Starting Sprout with a drive disconnected keeps playtime and launch settings; reconnect it and use **Check again** on the game page.
- **Downloads and saves:** Direct HTTP downloads stream to disk and only finish after the file is saved. Library, settings, and download queue writes preserve the previous file on failure and retry pending changes.
- **Launching games:** Linux runtime setup runs in the background and can be cancelled. Linux install-layout repair merges colliding directories instead of discarding them. Windows waits for the matching game process before showing it as running. Steam startup is requested at most once per launch.
- **Plugins and online services:** Busy plugins stay loaded while catalog or download work is in progress. Quitting requests a cooperative stop for plugin downloads. Sprout also checks plugin launch-option compatibility, detects catalog changes it could previously miss, and keeps friend aliases when the relay returns an invalid response.
