# Sprout v0.3.0

Sprout now includes the latest Arachnel release (launcher v2), merged with everything Sprout already had. Sprout keeps its Meadow look and its own fixes.

## New look, still Meadow

- A navigation drawer replaces the rail. It collapses to icons on narrow windows, and there are shortcuts: Esc goes back, Ctrl+1–6 switch tabs, Ctrl+, opens settings.
- Settings is a two-pane page with grouped sections; Debrid and the Hydra Library are still there.
- New game page: a large poster, colours taken from the cover, actions next to the title, an install panel instead of bottom sheets, and full trailers. Playtime, achievements, TorBox availability and **Open game folder** are all still there.
- New colour picker. **Meadow** stays the default and is now one of the styles; Daylight and Dusk are still the theme choices.
- Smoother page transitions, plus a **Reduce motion** setting.
- Media viewer: arrow keys flip through screenshots, and videos have a seek bar and keyboard shortcuts.
- Windows: hover the maximize button to get Snap Layouts, and the window can now be snapped to half the screen.

## Faster

- The catalog starts much faster: it is cached between launches, refreshed in the background, and filtered on multiple CPU cores.
- The catalog shows every match instead of stopping at 8,192 rows.
- Smarter search: whole-word matches rank first, small typos are forgiven, and titles match across alphabets.
- Covers load 16 at a time and no longer ask for images that don't exist.
- Library saves are batched and written safely, so a crash can't leave a half-written `library.json`. Playtime is still saved immediately.

## Fixes

- Removing a plugin no longer freezes the window. A plugin's own running download still blocks its removal, and other plugins' downloads no longer delay it.
- Online Fix (OF.me) games are no longer switched off after a quick exit.
- Missing game descriptions are now fetched from Steam's US store, so region-locked games get one too.
- Fixed an endless cover-loading loop that could freeze the window.
- The adult-content filter keeps working now that the catalog is filtered in the background.
