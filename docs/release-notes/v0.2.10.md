# Sprout v0.2.10

- Fix a Windows update hang caused by waiting for the torrent engine on the UI thread. Torrent shutdown now finishes on a worker, and TorBox-only use no longer starts the local torrent engine.
- Show TorBox cache badges in game details and download source selection. Cached, uncached, checking, and unavailable states are distinct; direct links are labeled separately. Availability checks do not change download routing.
- Add library search, title/recent/playtime sorting, and persistent Backlog, Playing, and Completed lists in game settings.
- Add achievement search and locked/unlocked filters, unlock dates, and optional in-app notifications. Progress refreshes during tracked play even with the details page closed. Existing achievements are not announced again.
- Make the saved "Hide adult games" switch visible at the top of Catalog filters, without opening "More".
- Keep saved download recovery and TorBox routing intact. Add Windows and Linux regression checks for delayed torrent shutdown, library persistence, cache errors, and achievement notifications.

When installing this version from v0.2.8 or v0.2.9, fully close Sprout and any Sprout error reporter first. Those older versions still contain the shutdown bug; the fix takes effect after installing v0.2.10.
