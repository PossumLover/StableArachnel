# Sprout v0.3.9

- Open **Game settings → Import Online Fix package…** to apply an extracted package to an installed game. Sprout matches Steam packages by `RealAppId`. GDK updates require a matching `ProductId` in the installed `OnlineFix.ini` at the same relative path.
- Sprout preserves the package’s folder layout and backs up the files it replaces. Choose **Restore pre-import files** to undo the import before applying another package. Restoring also removes files added by the import and replaces later edits to imported files.
