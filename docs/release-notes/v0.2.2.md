# Sprout v0.2.2

A fix for Online Fix in nested repacks, and a new **Verify files** button.

## Fixes

- **Online Fix now gets the game's real AppId in nested repacks.** When the fix sits in the install folder but the game's exe is one folder down, Sprout copies the fix next to the exe. On a fresh install that copy never got the game's real AppId, so the game was still told it was Spacewar, and games that check their own id quit. The real id now goes into every copy of the fix's settings.
- A failed download or verify no longer makes an installed game look unplayable.

## New

- **Verify files**, in a game's settings, works like Steam's "verify integrity of game files". For games from sources that download the game themselves (steamidra), every file is checked against the source and only what's missing or damaged is downloaded again.
  - Modded game files go back to the originals.
  - A pending update for the game is installed along the way.
  - Your DLC and your Online Fix on/off choice are kept.
  - Torrent sources can't be checked, and the button says so.

## Updating

- **Windows:** use Update now in the app. The installer runs by itself and reopens Sprout.
- **Linux AppImage:** from 0.2.1, Update now swaps the AppImage in place and restarts Sprout. On 0.2.0, download this AppImage by hand once.

## Downloads

- **Windows:** `SproutLauncher-0.2.2-Setup.exe`
- **Linux:** `SproutLauncher-0.2.2-x86_64.AppImage`
- `checksums.sha256`: SHA-256 of both
