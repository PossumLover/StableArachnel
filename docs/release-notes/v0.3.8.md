# Sprout v0.3.8

- Steam games whose Online Fix could never load now switch to SteamFix automatically when you launch them. Sprout's Steam plugin installs Online Fix without the loader file it needs, so in those games it never started. Some games then hung on a black screen, like Invokyr; others quit right away, like Valheim. The Online Fix files are backed up first.
- The switch covers games that keep a copy of the fix next to the real game program as well as next to the launcher, like Unreal Engine games such as Far Far West. If the switch fails partway, Sprout puts the original files back before launching.
- Game settings now show whether a game uses Online Fix or SteamFix. Online Fix games get a **Use SteamFix** button for when Online Fix starts but misbehaves. Games using Unsteam never get the button.
- Launching a game is faster when it's installed on a hard drive. Sprout used to search the game's folder up to seven times before starting it, and now searches it once.
- Sprout no longer freezes for a few seconds when a game closes. Its achievement check re-scanned the game's install folder to look up the Steam app ID, and it did that every 15 seconds while you played too. That's slow on a hard drive. It now uses the ID already saved in your library.
