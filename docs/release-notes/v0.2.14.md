# Sprout v0.2.14

- Fix earned achievements appearing locked when a game's save and achievement details use different capitalization. Unlock counts, secret achievement details, icons, dates, and notifications now use the same case-insensitive matching. Previously cached progress is recognized without replaying old unlock notifications.
- Read Goldberg/GSE achievement saves at `<installPath>/steam_settings/<appId>/achievements.json`, including object and array formats. Sprout checks the selected game's app ID so another game's saves and the achievement definition file are not counted as progress.

Includes everything in v0.2.13, including the plugin update crash fix, download speeds, and smoother TorBox progress updates.
