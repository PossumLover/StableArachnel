# Sprout v0.3.10

- The running game now sits in the side menu above Settings, with its cover, title and a stop button. The "Playing now" bar at the top of the page is gone, so pages no longer start with a blank strip while you play. With the menu collapsed you still see the cover and the stop button.
- Game settings are reorganized into Launch, Compatibility, Files and updates, and Shortcuts. Fields have labels, launch modes are a plain list to pick from, and the two shortcut buttons are now one **Create shortcut** menu. Install details are tucked under **Installation details**. When **Verify files** is unavailable, the sheet says why.
- Library lists (Backlog, Playing, Completed) are out of game settings and easy to reach. Use the **List** button next to Favorite on a game's page, or right-click a game in the library. Each card shows its list, filter chips under the search box switch lists, and an empty list tells you how to add games.
- **Open game folder** and **Launch log** moved into the ⋮ menu on a game's page. The Play button uses the app's colors instead of the cover's, so it's readable on every game.
- You can move through the side menu with the keyboard.
