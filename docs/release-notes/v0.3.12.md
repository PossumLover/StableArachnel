# Sprout v0.3.12

- **Browse** replaces the Catalog tab. Pick a genre from the panel on the left, or **All games**, then filter, sort and search as before.
- Browse opens on the most recently uploaded games instead of an alphabetical list. A bug that dropped upload dates from the saved catalog is fixed, so **Recently uploaded** sorts correctly again, and the sort button shows the order you picked.
- The genre panel lists real genres with how many games each one has, most popular first. Rare genres are under **More genres**, or you can find them with **Find a genre**. Store tags like Free to Play and Early Access are no longer listed as genres.
- Genres have clearer icons, and the Browse search bar matches the one in your library.
- Game cards show the download size and leave out meaningless build numbers. The background illustration no longer shows through behind the game list.
- When nothing shows up, Browse offers a way out: **Clear search**, **Clear filters**, **Choose sources** or **Refresh catalogs**. While catalogs are still loading, it says so instead of showing "nothing found".
- Sprout uses less memory. On Windows it now hands memory it no longer needs back to the system, so it settles lower after loading the catalog and after browsing. Loading the catalog also takes less memory than before.
- Library and catalog posters line up the same way, and the sidebar expands smoothly.
- Removing a plugin works again after closing and quickly reopening Sprout.
- Library rows are tighter, and the actions on a game's page line up.
