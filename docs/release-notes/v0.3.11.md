# Sprout v0.3.11

- Sprout uses less memory. On Windows it now hands memory it no longer needs back to the system instead of holding on to it, so it settles lower after loading the catalog and after browsing. Loading the catalog also takes less memory than before.
- The Catalog tab is now **Browse**: pick a genre from the panel on the left, or **All games**, then filter, sort and search as before.
- Library and catalog posters line up the same way, and the sidebar expands smoothly.
- Removing a plugin works again after closing and quickly reopening Sprout.
- Library rows are tighter, and the actions on a game's page line up.
