# Sprout v0.2.4

A fix for renaming friends.

## Fixes

- **Renamed friends keep their new name.** Sprout checks your friends' status every few seconds, and each check put back the name the friend picked for themselves. A rename lasted a few seconds, then went back to something like "Arachnel 12345". Your rename is now kept on your computer, separate from the friend's own name, and stays after restarts. Only you see it: the new name isn't sent to your friend.
- Friends you haven't renamed still show their own name, and it updates when they change it.
- To go back to a friend's own name, clear the name in **Rename friend** and save, or type their current name.

Names you set before this update weren't saved, so rename those friends once more.

## Updating

- **Windows:** use Update now in the app. The installer runs by itself and reopens Sprout.
- **Linux AppImage:** from 0.2.1, Update now swaps the AppImage in place and restarts Sprout. On 0.2.0, download this AppImage by hand once.

## Downloads

- **Linux:** `SproutLauncher-0.2.4-x86_64.AppImage`
