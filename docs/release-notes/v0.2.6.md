# Sprout v0.2.6

This update adds TorBox torrent downloads and support for protected Hydra catalogs.

## Changes

- Add **Settings > Debrid** with a TorBox API key, connection test, and download switch.
- Route all torrent downloads through TorBox while enabled, including updates, add-ons, restored jobs, and retries. Unfinished peer downloads switch to TorBox, and paused jobs stay paused.
- Stop background peer metadata probes while TorBox is enabled. Provider failures never fall back to peer downloads.
- Stream TorBox files into their original folder layout with pause, resume, and partial-file recovery. Direct HTTP downloads stay direct.
- Load catalogs on `hydralinks.cloud` and `hydralinks.pages.dev` through Hydra's indexed API, and fetch download links when a download starts.
- Store the API key separately from settings and download history. Windows uses DPAPI; Linux uses a private key file.
- Add download regression tests and an Ubuntu workflow that builds the Linux launcher and checks Linux file permissions and symlink handling.
- Add English and Russian strings for the new settings and download states.

## TorBox setup

Open **Settings > Debrid**, paste your API key, choose **Save and test**, then enable **Use TorBox**. Your TorBox subscription must support API access.

Existing peer files are preserved, but TorBox transfers use a separate folder. Canceling a local download does not remove the remote torrent from TorBox. Downloads already assigned to TorBox keep that method when the switch is turned off.

See the [download guide](https://github.com/PossumLover/StableArachnel/blob/v0.2.6/docs/torbox-hydra.md) for details and current source limitations.
