# Sprout v0.2.7

This update fixes the Debrid settings controls and catalog duplicates, and adds playtime and local achievements.

## Fixes

- Fix the Debrid form intercepting clicks. The TorBox switch, API key field, and save/remove actions now respond to mouse input.
- Group catalog titles that differ by version, build, language labels, or "Free Download" suffixes. Steam app IDs take priority, and conflicting IDs stay separate. Each source keeps its latest download offer.
- Preserve catalog search text when sources change and stop hidden catalog pages from submitting pending searches. Search now updates after a shorter typing delay.
- Retain Steam app IDs supplied in Hydra download feeds.

## Game activity

- Add total playtime to library cards and game details, plus the last completed session in game details. Sessions save periodic checkpoints and exclude failed starts and automatic retries.
- Add an Achievements panel for installed games with known Steam IDs, with icons, descriptions, unlocked totals, hidden secret achievements, and offline caching.
- Read OnlineFix, Goldberg/GSE, and CODEX/RUNE achievement files on Windows and inside Linux Proton prefixes.
- Add English and Russian translations.

Playtime starts with this update. Achievement progress depends on a supported local save format. See the [game activity guide](https://github.com/PossumLover/StableArachnel/blob/v0.2.7/docs/game-activity.md).

Both release builds run download, catalog, playtime, achievement, and QML interaction regression checks before publication. The Windows resize issue remains for a later update.
