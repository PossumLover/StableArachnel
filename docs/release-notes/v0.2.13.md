# Sprout v0.2.13

- Fix a crash a few minutes after updating Sprout. After an app update, Sprout reinstalls its plugins, which unloads the old plugin files. The library, the download list and the catalog still held text that lived inside those files, such as the Steam source's name, so the next library save crashed. Sprout now keeps its own copy of everything a plugin gives it.
- Show the download speed and time left for direct and TorBox downloads. The speed was measured between progress updates that arrive too close together, so it never appeared.
- TorBox downloads now update the download list a few times a second instead of on every network read, which kept Sprout busy on fast connections.
- Turning on TorBox no longer freezes the window for about a second while Sprout stops reading magnet links in the background.

Includes everything in v0.2.12, including the fix for the crash right after a Steam game finished installing.
