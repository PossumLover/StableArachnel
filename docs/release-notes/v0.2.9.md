# Sprout v0.2.9

Remove the white strip above the custom title bar on Windows while preserving window resizing.

- Extend the launcher content over the exposed top resize border.
- Keep native resizing, minimum size, and maximize/restore behavior.
- Apply the same correction to the crash report window.
- Keep maximized content inside the desktop work area and fullscreen content inside the monitor.

Windows builds check the top frame position, all eight resize directions, recreated windows, minimum size, maximize/restore, and fullscreen. Both platforms run the existing download/activity and QML interaction checks before publication.

## Downloads

- **Windows:** `SproutLauncher-0.2.9-Setup.exe`
- **Linux:** `SproutLauncher-0.2.9-x86_64.AppImage`

The files without a version in their names are identical copies for stable download links. Verify downloads using `checksums.sha256`.
