# Sprout v0.2.11

- Fix additional duplicate catalog cards when many sources are enabled. Recognize parenthesized builds, multi-digit versions, GOG/P2P/Portable tags, and repack metadata.
- Associate download listings with edition names, event labels, or release codes with a unique known Steam game. Exact Steam titles and explicit app IDs take precedence; demos, playtests, dedicated servers, sequels, remasters, and DLC stay separate.
- Add regression coverage using the Core Keeper titles observed in the installed catalog, including ambiguous titles and similar prefixes.

Includes the v0.2.10 updater shutdown fix, TorBox cache badges, library lists and sorting, achievement filters and notifications, and the adult-game switch at the top of Catalog filters.

When updating from v0.2.8 or v0.2.9, fully close Sprout and any Sprout error reporter before running the installer. The older versions still contain the shutdown bug.
