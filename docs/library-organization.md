# Library organization

Search installed games by title and filter them by **Backlog**, **Playing**, **Completed**, or **Unorganized**. Assign a game to a list from its **Game settings > Library list** control. Existing games start in Unorganized. Lists are saved with the library and survive updates and restarts.

Sort by Title, Recently played, or Most played. Title uses natural ordering, so Game 2 comes before Game 10. Recent and playtime sorting use Sprout's recorded sessions; unplayed games follow played games when sorting by recent activity. The chosen sort is remembered. Search and list filters are temporary and do not hide games from launch tracking or affect downloads.
